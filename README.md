A deadpan one-star review of an everyday essential, in one line of 160 characters or fewer. Built for the [One-Star Review of Something Essential](https://make.fun/competitions/u-0xb3e689-one-star-review-of-something-essential-c7234629) bounty on make.fun.

## How it works

`main.ts` (Node 22, standard library only, deterministic) writes a single line — a one-star review of sleep, filed in earnest against a thing that cannot be fixed — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

## Entry

> Sleep: one star. Eight hours in, woke up tired, no refund. Asked for the manager; he was asleep.
